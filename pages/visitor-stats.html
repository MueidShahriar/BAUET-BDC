How Visitor Tracking Works

1

Page Views — Each page tracks visits independently. A browser session is counted once per page each day, so refreshes do not inflate the numbers.

2

Online Users — Uses Firebase presence system. When you open the site, you're marked as "online". When you close the tab, you're automatically removed.

3

Real-time — All numbers update instantly across all connected browsers without any page refresh needed.

4

Privacy — No personal data is collected. Only anonymous session IDs are used for counting purposes.

Recommended Database Rules 

{
  "rules": {
    "visitorTracking": {
      "totalViews": {
        ".read": true,
        ".write": "newData.isNumber() && newData.val() >= 0"
      },
      "pageViews": {
        ".read": true,
        "$page": {
          "$metric": {
            ".write": "newData.isNumber() && newData.val() >= 0"
          }
        }
      },
      "dailyViews": {
        ".read": true,
        "$date": {
          ".write": "newData.isNumber() && newData.val() >= 0"
        }
      },
      "presence": {
        ".read": true,
        "$sessionId": {
          ".write": "newData.val() === null || (newData.hasChildren(['updatedAt', 'path']) && newData.child('updatedAt').isNumber() && newData.child('path').isString())"
        }
      }
    }
  }
}

These rules allow anonymous, session-based tracking on the static site while restricting presence records to an expiry timestamp and page path. Session IDs are random and contain no member identity.
